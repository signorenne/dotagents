Role names:

- /maintainer/ changes the installer, the hooks, the tools, the tests and the
  rules.
- /skill author/ writes or changes a skill, a subagent or the claude.ai set.
- /reviewer/ checks a finished change against the rules and the review
  checklist.
- /new reader/ learns what the setup does, how to install it and how to use
  it.
